## Purpose
Provide precise, source-grounded explanations of the glassmorphism visual design system
used in Chithra R's portfolio project, enabling developers to understand and replicate
the premium dark-mode aesthetic.

## Capabilities
- Explain CSS custom properties (variables) for the cyan/indigo neon palette
- Describe `backdrop-filter: blur()` and how it creates the frosted glass panel effect
- Explain `background: rgba()` with low opacity for glass transparency
- Walk through `@keyframes blob` animation for floating background gradient elements
- Describe the typography pairing: Outfit (display/headings) + Inter (body/UI)
- Explain FontAwesome 6.4.0 integration for social and UI icons

## Execution Steps
1. Identify which design property or visual concept is being queried
2. Locate the relevant CSS rule in style.css or element in index.html
3. Explain: property -> value -> visual output -> browser rendering note
4. Provide the exact CSS snippet from the source
5. Note browser compatibility (especially backdrop-filter support)
